## Reporting a vulnerability

If you believe you have found a security issue in this repository or related Horizon PREVIEW surfaces, please report it privately. Do **not** open a public issue with exploit detail, secrets, or customer data.

**Report path:** email `security@advancedfrontier.tech` (or the address listed on the Advanced Frontier Technologies / Advanced Universal Solutions, LLC security contact page when published).

Include:

- A short description of the issue
- Steps to reproduce (non-destructive)
- Affected surface or path if known (Chatbot / Containment / Kids PREVIEW)
- Your contact for follow-up

## Scope notes

- This public tree is a **thin PREVIEW scaffold**. It is not a production service and is not customer GA.
- Do not submit secrets, credentials, PHI, or personal data belonging to children.
- Kids PREVIEW is **COPPA HOLD** — no under-13 accounts or child data collection in this repo.

We will acknowledge receipt when staffed. This file is a report path only; it is not a vulnerability disclosure dump or a compliance certification.
